TALVERA HEAT — Streets of Talvera: an original open-world crime game in the browser. Drive and walk a sun-baked river city, steal cars, outrun the Talvera PD through five wanted stars, and run six story jobs for fixer Selma Voss. Built with three.js (vendored, offline), a HUD with a live minimap, procedural Web Audio music and sound, and a save system.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to drive or walk, E to enter and exit cars, F to punch, click to shoot, T to start a job at the garage marker, P to pause, M to mute.
